# Personal Website

Live at [emrebozkurt.de](https://emrebozkurt.de).

A professional introduction for Emre Bozkurt, a software engineer based in Munich. The visual design is inspired by early-2000s street-racing menus, using original CSS artwork. The page links to LinkedIn, GitHub, and email.

## Requirements

Node.js 20.19+ or 22.12+ and Yarn Classic 1.22.22.

## Development

```bash
yarn install
yarn dev
```

Vite prints the local development URL when it starts.

## Build and preview

```bash
yarn build
yarn preview
```

The static site is built into `dist/`. `public/CNAME` is copied into that directory for GitHub Pages. To publish it, run `yarn deploy`.

## Stack

React 19, TypeScript, Vite, CSS, and Font Awesome.
